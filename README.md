# Customer Churn Prediction

## Project Overview

This project predicts whether a customer is likely to churn based on customer demographic and service-related information.

The project uses machine learning techniques to analyze customer data and build a predictive model for customer churn.

## Dataset

The project uses the Telco Customer Churn dataset.

The dataset contains information about:

- Customer demographics
- Account information
- Services used
- Contract details
- Monthly and total charges
- Customer churn status

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning

The project includes:

- Data preprocessing
- Exploratory Data Analysis
- Feature engineering
- Model training
- Model evaluation
- Customer churn prediction

## Project Files

- `Telco-Customer-Churn.ipynb` — Complete analysis and machine learning workflow
- `Telco-Customer-Churn.csv` — Dataset
- `best_model.pkl` — Trained machine learning model
- `feature_names.pkl` — Feature names used by the model
- `preprocessor.pkl` — Data preprocessing object

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open `Telco-Customer-Churn.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells sequentially.

## Objective

The main objective of this project is to identify customers who are likely to churn and demonstrate how machine learning can be used for customer retention analysis.
